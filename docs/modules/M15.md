# Module M15 — Portal de Operadores Logísticos e Frotas (`apps/admin-web`, `packages/domain`)

## 1. Scope & Architecture
- **Fleet access guard (`evaluateFleetOperatorAccess`)**:
  - Returns `DISABLED_PENDING_FLEET_CONTRACT` when the fleet contract is not approved.
  - Returns `DENIED_CROSS_FLEET_OR_INDEPENDENT_COURIER` when the actor is not a member of the fleet organization, when the target courier is independent (`fleetOrganizationId = null`), or when the courier belongs to another fleet.
- **Portal model (`buildFleetOperatorPortalModel`)**:
  - Returns `portalStatus` and only the couriers belonging to the actor's own fleet.

## 2. Status
- The portal is **disabled by default** (`DISABLED_PENDING_FLEET_CONTRACT`) until fleet contracts are enabled commercially, as defined in the Master Plan.
- No dedicated `/v1/fleet/*` HTTP endpoints or fleet-specific RLS policies exist yet; these are required before enabling the portal in production.
