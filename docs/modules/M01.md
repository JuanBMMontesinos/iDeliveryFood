## 1. Objetivo e Escopo

O módulo **`M01`** estrutura o monorepo `pnpm` com 14 projetos TypeScript (`8` pacotes compartilhados sob `packages/*` e `6` aplicações sob `apps/*`) além dos 4 projetos mobile nativos (`apps/customer-android`, `apps/courier-android`, `apps/customer-ios`, `apps/courier-ios`).

## 2. Rotas `/v1` e Contratos Fundamentais

| Método e Rota | Descrição | Autenticação |
| :--- | :--- | :--- |
| `GET /v1/health/live` | Liveness probe do processo HTTP (`status: "ALIVE"`, `version: "v1"`). | Pública |
| `GET /v1/health/ready` | Readiness probe verificando `databaseProjectRef: "dwsoochnfxldfvcaijie"`, fuso `America/Sao_Paulo`, moeda `BRL` e provedores externos. | Pública |
| `GET /v1/system/providers` | Lista status honesto (`ACTIVE`, `SANDBOX_READY`, `BLOCKED_MISSING_CREDENTIALS`) dos adaptadores registrados. | Pública |
| `PATCH /v1/me/preferences` | Persiste preferência de idioma (`en` ou `pt-BR`) e opt-in de notificações em `public.profiles` e `public.user_preferences`. | Bearer JWT (`authenticated`) + `X-Idempotency-Key` |

## 3. Tabelas de Banco de Dados Relacionadas

- `public.provider_configurations`
