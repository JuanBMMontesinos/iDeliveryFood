## 1. Objetivo e Escopo

O módulo **`M02`** provisiona e governa a plataforma de dados no projeto Supabase **`dwsoochnfxldfvcaijie`** (`PostgreSQL 17`), garantindo que **100% das 59 tabelas públicas** possuam Row Level Security (`rowsecurity = true`) e estejam populadas (`>= 1` registro real/seed com `is_test_data = true`), além de **4 views `WITH (security_invoker = true)`** e **13 buckets Storage** endurecidos.

## 2. Componentes de Banco de Dados

1. **15 Migrations Versionadas (`supabase/migrations/`):**
   - Criam tipos enumerados, 59 tabelas de domínio (`M01`–`M22`), índices de chave estrangeira, índices parciais de unicidade (`uq_delivery_assignments_one_active`), triggers append-only (`trg_order_events_immutable`, `trg_ledger_entries_immutable`, `trg_audit_logs_immutable`, `trg_courier_location_samples_immutable`, `trg_delivery_events_immutable`, `trg_payment_provider_events_immutable`, `trg_risk_decisions_immutable`) e o trigger de equilíbrio de partidas dobradas (`trg_verify_journal_balanced`).
2. **4 Views `security_invoker = true`:**
   - `public.published_stores_v`, `public.store_catalog_v`, `public.ledger_account_balances_v`, `public.analytics_order_kpis_v`.
3. **13 Buckets Storage (`storage.buckets` + `storage.objects` RLS):**
   - `public-store-assets`, `store-assets`, `catalog-media`, `private-kyc-docs`, `merchant-documents`, `courier-documents`, `private-pod-evidence`, `delivery-proofs`, `private-support-attachments`, `support-attachments`, `private-financial-exports`, `financial-statements`, `privacy-exports`.
4. **Seed Idempotente (`supabase/seed.sql`):**
   - Pode ser executado $N$ vezes seguidas sem duplicar linhas (`ON CONFLICT DO UPDATE` / `DO NOTHING`), populando todas as 59 tabelas com `is_test_data = true` e e-mails RFC 2606 (`.invalid`).
