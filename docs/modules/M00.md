## 1. Objetivo e Escopo Arquitetural

O módulo **`M00`** estabelece a fundação conceitual, as invariantes de negócio e os contratos de arquitetura do ecossistema **iDeliveryFood**, garantindo alinhamento entre backend (`/v1` API + Worker), banco de dados PostgreSQL/Supabase (`dwsoochnfxldfvcaijie`), 3 portais web Next.js e 4 aplicativos mobile 100% nativos (Kotlin/Jetpack Compose e Swift/SwiftUI).

## 2. Invariantes Globais Definidas em `M00`

1. **Padrão Monetário Invariável (`BRL` em Centavos Inteiros):**
   - `CURRENCY_CODE = "BRL"`. Todos os preços, taxas, descontos, comissões e saldos contábeis são armazenados e calculados como inteiros (`*_cents`), proibindo `float`/`double`.
   - Alternar o idioma da interface entre `en` e `pt-BR` altera exclusivamente a formatação textual/separadores (`R$ 38.90` vs `R$ 38,90`), nunca a moeda ou o valor em centavos.
2. **Padrão Temporal (`UTC` + `America/Sao_Paulo`):**
   - `OPERATIONAL_TIMEZONE = "America/Sao_Paulo"`. Timestamps são persistidos em UTC (`timestamptz`) e avaliados para janelas operacionais de lojas no fuso `America/Sao_Paulo`.
3. **Internacionalização Bilíngue (`en` Padrão + `pt-BR` Selecionável):**
   - `SUPPORTED_LOCALES = ["en", "pt-BR"]`, `DEFAULT_LOCALE = "en"`. Paridade de 100% das chaves validada automaticamente.
4. **Modalidades Híbridas de Fulfillment:**
   - `PLATFORM_DELIVERY` (logística da plataforma via `M14`/`M11`), `MERCHANT_DELIVERY` (entrega própria da loja) e `PICKUP` (retirada na loja).
5. **Adaptadores Externos com Bloqueio Honesto:**
   - Provedores pré-configurados (`stripe`, `mercadopago`, `pagarme`, `google_maps`, `mapbox`, `resend`, `fcm`, `apns`) reportam `BLOCKED_MISSING_CREDENTIALS` quando variáveis de ambiente de produção não estão injetadas, nunca simulando sucesso falso.
